# 문서 폴더 (documents)

챗봇이 답변의 근거로 쓰는 협약서·복지 안내문 PDF를 넣는 곳입니다.
이 폴더의 PDF는 배포할 때 자동으로 읽혀 질문 답변에 쓰입니다. (DESIGN.md 3.1)

## 넣는 방법

1. 복지·협약 담당자가 PDF를 정보화 담당에게 보냅니다.
2. 정보화 담당이 아래 규칙을 확인하고 이 폴더에 넣습니다.
3. 앱을 다시 배포하면 화면의 "현재 참고 문서 목록"에 "문서 준비 완료"가 표시됩니다.

## 넣기 전에 확인할 규칙 (PRD 5번, 7번)

| 확인 | 규칙 |
|---|---|
| ☐ 공개 등급 | 외부에 공개되어도 문제없는 **공개 등급 문서만** 넣습니다. 대외비·비공개·내부 한정 문서는 넣지 않습니다. |
| ☐ 개인정보 | 이름·연락처·주민등록번호·계좌번호가 있으면 그 부분을 지운 사본을 넣습니다. |
| ☐ 파일 형식 | **PDF만** 넣습니다. 한글(HWP) 문서는 PDF로 변환해서 넣습니다. |
| ☐ 글자 확인 | PDF에서 글자를 마우스로 선택할 수 있어야 합니다. 스캔한 이미지 PDF는 읽을 수 없습니다. |
| ☐ 크기·개수 | 파일 1개당 **20MB 이하**, 폴더 전체 **최대 10개**까지입니다. 넘으면 오래된 문서부터 뺍니다. |
| ☐ 파일 이름 | 앞에 문서 날짜를 붙입니다: `YYYY-MM-DD_문서이름.pdf` (예: `2026-03-01_○○병원협약.pdf`) |

## 파일 이름에 날짜를 붙이는 이유

- 같은 협약의 옛 문서와 새 문서가 함께 있을 때, **날짜가 최신인 문서를 기준으로** 답하기 위해서입니다.
- 문서가 10개를 넘을 때 **어떤 문서가 오래됐는지** 판단하기 위해서입니다.

## 주의

- 이 폴더의 문서는 프로젝트와 함께 GitHub(비공개 저장소)와 Vercel에 올라갑니다. 그래서 공개 등급 규칙을 꼭 지켜 주세요.
- 이 안내 파일(`README.md`)은 답변 근거로 쓰이지 않습니다. PDF만 읽습니다.
